# Erdős problem statements, formalized from the source pages

There are 248 Lean files, one per Erdős problem. Each file starts with the problem text exactly as erdosproblems.com served it, frozen on the day it was fetched, followed by a Lean statement of the problem. Most files contain statements only. A few also prove small supporting facts, listed in [FORMALIZER-STATE.md](https://github.com/jaredwilder/paper-formalizations/blob/main/sources/FORMALIZER-STATE.md). The `entry-graph-*.json` files record how each page was split into its question, its resolution and its notes.
